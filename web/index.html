06 / Reference QA

Prepare a separate local page catalog, inspect the selected pages, then ask the configured reference model.

Select a project first.
Preparation and preview are local. Only Ask reference model may make a configured model request.

Reference evaluation tasks

Freeze an ordered question set against this source snapshot and model profile. Only an explicit Run question action may call the model.

Managed execution jobs

After explicit confirmation, CIRP can continue the frozen task one question at a time even if this page closes. Interrupted work never resumes automatically.

Compare same-snapshot evaluations

Compare two frozen tasks only when their run, snapshot, and ordered questions are identical. This reports saved outcome differences and does not decide correctness.

Local input plan

Inspect the pages and input size for every question before authorizing a run. The plan contains no source text and makes no model call.

Human benchmark scorecard

Classify terminal answers against the independent source answer. CIRP records the human verdict and threshold math but never infers correctness.

Saved reference results

Compare saved Reference runs

This reports stored answer differences only. It does not decide which answer is correct or controlling.

Human follow-up

Create a local, auditable follow-up only when you choose it. It never changes the model answer or calls a model.
