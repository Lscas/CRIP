# Source-layout navigation — selector v9

When the request includes layout_navigation, each parts[].ref names the current
original E evidence row. Use these references to find and cite the original
evidence, not the navigation. Navigation is non-citable: it cannot replace a
source quote or provide numeric or calculation support.

unbound_refs means that a source could not be mapped to supported layout. Its
original text remains available. A valid source can be absent from columns
because it does not qualify as a multi-column view; this does not make it
unbound or missing.

Parts preserve observed text order and current source references only. Equal
text or numbers, proximity, and shared lines or columns do not prove object
identity, units, conditions, relationships, arithmetic bases or support. Resolve
these from original evidence. If required relationships remain unsupported,
request the specific missing evidence or report that you cannot answer. All
existing claim, exact-citation, numeric and calculation rules still apply.
