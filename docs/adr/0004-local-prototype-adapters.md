# ADR-0004：第一开发切片的本地适配器
日期2026-09-08；依据用户“开始搭建项目”授权，属于可逆实现选择，不改变产品业务范围。

采用FastAPI模块化单体 + 内嵌静态网页 + SQLite WAL + 本地对象文件 + 单后台线程。原型只监听127.0.0.1，用进程文件锁确保单应用实例。生产目标PostgreSQL、对象存储、认证和任务队列保留在后续计划。
理由：现阶段一个活跃项目、无GPU、无供应商Key，避免在第一个可运行版本引入多套部署依赖。原始文件4MiB分片落盘，完成时流式哈希；没有10GB压测证据，不宣称达到此容量服务等级。

单用户开发环境不等于多租户安全产品。Host/Origin与自定义写请求头只能作为本地保护，不是登录认证。解析子进程有超时和有限输入检查，但不是安全沙箱。不得对外开放。

预算SQLite事务原子化，与旧contracts内存参考分开；网络超时保持预留，人工账单对账功能尚未交付。停用真实API默认零费用。导出不调用模型。

回滚：切换spec-v0.2.0仅恢复规格，不删除.local。数据库迁移001用于新工作区；生产数据库迁移不在此次交付。将来替换存储适配器需新迁移和集成测试，不把数据库变化藏在Prompt中。
