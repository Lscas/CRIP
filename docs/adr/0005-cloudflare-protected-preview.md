# ADR-0005：受保护的Cloudflare测试入口
状态：采用；授权来源为用户明确要求开始部署并搭建Cloudflare远程测试页面。

保留本地Python、SQLite和解析Worker，避免为展示原型重写Cloudflare运行时。提供临时Tunnel和Pages鉴权代理两种入口；不自动租用主机或改变现有域名。可公开浏览的正式站点必须真实发布并通过HTTP验证后才记录为完成。

云端静态资产与客户上传资料隔离；访问高熵密码和源站Token分别生成。付费模型仍关闭，本次授权不等于用户已经提供并验证模型API。Pages必须Fail closed；无法确认则停止。不会把远程预览鉴权标记为完整生产身份平台。

当前执行环境没有Cloudflare授权且外网DNS失败，因此仅落实代码、测试、启动与部署流程，公网状态BLOCKED。授权不等于获得账户技术访问能力。
